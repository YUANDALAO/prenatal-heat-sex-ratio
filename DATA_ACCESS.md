# Data access

| Data | Provider | Access | Where the code expects it |
|---|---|---|---|
| DHS Births Recode (BR), Women's Recode (IR) and GPS (GE) files, Stata format, all surveys with GPS | The DHS Program | Free application at https://dhsprogram.com, including the GPS datasets | `dhs_raw/` (ZIP files under their DHS names, e.g. `NGBR7BDT.ZIP`, `NGGE7BFL.ZIP`) |
| MIS and AIS files with GPS (replication) | The DHS Program | Same application | `dhs_raw/mis_ais/` |
| Monthly 2 m temperature, maximum and wet-bulb temperature | NASA POWER (MERRA-2) | Public; read anonymously from AWS by `power_monthly.py` | `data/power_monthly_anom.zarr` |
| Live births by country, 2023 | UN World Population Prospects 2024, demographic indicators (medium variant) | Public download, `WPP2024_Demographic_Indicators_Medium.csv.gz` | `data/wpp_demo.csv.gz` |
| Armed conflict events | ACLED | Free myACLED account; `acled_token.py` asks for the password in a hidden prompt and stores only a temporary token in `data/.acled_token.json` (never commit it) | `data/acled/` |
| Georeferenced conflict events, GED 26.1 | UCDP | Public, https://ucdp.uu.se/downloads/ged/ged261-csv.zip | `data/ucdp/ged261-csv.zip` |

`build_births.py` maps each DHS file to its survey through `dhs_raw/urls_needed.txt`, the download list generated by the DHS website after approval (one URL per file, containing `Filename=` and `surv_id=`). `build_births_mis.py` uses the equivalent list for MIS and AIS files, `dhs_raw/urls_mis_ais_needed.txt`. Generate both from your own account.

National calendars (Ethiopia, Nepal) are detected and converted automatically; offsets are written to `data/survey_qc.csv` and can be checked against the copy in this repository.
